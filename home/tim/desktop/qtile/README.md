# Qtile session

Qtile is managed by Home Manager from this directory.

## Files

- `config.py`: window manager behavior, keys, screens and widgets.
- `theme.py`: generated by `qtile.nix` from `../palette.nix`.
- `wallpaper-dp1.png` and `wallpaper-hdmi.png`: managed by `qtile.nix` per output.

## Runtime helpers

The helper commands are provided by `home/tim/desktop/qtile.nix`:

- `qtile-apply-display-scale`
- `qtile-power-menu`
- `qtile-lock-and-suspend`
- `qtile-screenshot-area`
- `qtile-screenshot-full`
- `qtile-network-status`
- `qtile-docker-status`
- `qtile-kube-status`
- `qtile-polkit-agent`

## Display layout

- `HDMI-A-1`: secondary 1080p display, scale `1.0`, position `0,0`.
- `DP-1`: primary 4K display, scale `1.25`, position `1920,0`.

# Qtile session

Qtile is managed by Home Manager from this directory.

## Files

- `config.py`: window manager behavior, keys, screens and widgets.
- `theme.py`: palette, font and sizing values.
- `wallpaper.png`: generated by `qtile.nix` and linked into this directory.

## Runtime helpers

The helper commands are provided by `home/tim/desktop/qtile.nix`:

- `qtile-apply-display-scale`
- `qtile-power-menu`
- `qtile-lock-and-suspend`
- `qtile-screenshot-area`
- `qtile-screenshot-full`
- `qtile-network-status`
- `qtile-docker-status`
- `qtile-kube-status`
- `qtile-polkit-agent`

## Display layout

- `DP-1`: primary 4K display, scale `1.25`, position `0,0`.
- `HDMI-A-1`: secondary 1080p display, scale `1.0`, position `3072,0`.
